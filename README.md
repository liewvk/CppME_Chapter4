# C++ Programming Made Easy — Chapter 4

This repository contains the C++ source code and Visual Studio project files for Chapter 4 of the **C++ Programming Made Easy** series.

## Contents

- `CppME_Chapter4.cpp` — Main Chapter 4 source file
- `CppME_Chapter4_Example4.6/` — Example 4.6
- `CppME_Chapter4_Example4.9/` — Example 4.9
- `CppME_Chapter4_Example4.11/` — Example 4.11
- `CppME_Chapter4_Example4.13/` — Example 4.13
- `CppME_Chapter4_Example4.14/` — Example 4.14
- `CppME_Chapter4_Example4.17/` — Example 4.17
- `CppME_Chapter4.slnx` — Visual Studio solution
- `CppME_Chapter4.vcxproj` — Visual Studio project configuration
- `CppME_Chapter4.vcxproj.filters` — Visual Studio project filters

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/liewvk/CppME_Chapter4.git
   ```

2. Open `CppME_Chapter4.slnx` in Visual Studio.
3. Select a suitable build configuration and platform.
4. Build and run the project or any of the example projects.

You can also compile the standalone source files with a C++ compiler that supports the required language features.

## Purpose

The examples are intended for learning and practice while working through Chapter 4. Each example project demonstrates a topic or exercise from the chapter.
